# Notion連携(ファイル・プロンプト管理)

## 目的
Notionと連携し、ファイルやプロンプトを整理・管理する。

## 使う予定の連携
- Notion(MCP経由): プロンプトをデータベース(表)形式で管理
- Google Drive: 画像など重いファイルの置き場。フォルダ「04-notion-integration_images」を用意済み

## 決まっていること
- 今回はプロンプト管理のみに絞る(画像・一般ファイルの管理は将来的な拡張)
- PARA法などの上位分類は今は導入しない。プロジェクトが増えて必要になった時点で、
  リポジトリ・Notionの両方に後から被せる(移動だけで対応でき、作り直しは不要)

- 置き場: Notionページ「04_プロンプト管理」の配下
- URL: https://app.notion.com/723ec405e92c4a3098d656f8e713c822

- 旧ページ「プロンプト」「プロンプト2」の内容を移行済み。旧ページは削除せず残置(不要になったらユーザーが判断して削除)
