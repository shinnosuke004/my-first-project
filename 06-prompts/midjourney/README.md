# Midjourney汎用プロンプト管理

Craftの「prompt」スペースにあった「mj汎用版P」シリーズを、gitのブランチで管理する試験運用。

## 仕組み

- ファイルは常に `mj-general-prompt.md` の1つだけ。中身がバージョンによって変わる。
- 今いるブランチ(`claude/things-craft-migration-db-wa3abr`)には、現在実際に使っている版(Craftでの`v4`)を置く。
- 過去に試した別方向の版は、それぞれ別ブランチに分けて保存する。
  - `mj-prompt-v1` : Craftの`v1`(街区全体を一括変換する初期版)
  - `mj-prompt-v2` : Craftの`v2`(v1の微修正版)
  - `mj-prompt-v3` : Craftの`v3`(背景崩れ対策版。2番目によく使う版)

## 見方・使い方

- 今使っている版を見る: このブランチのままでOK
- 他の版を見たい: 該当ブランチをチェックアウトする(Claude Codeに「v3のブランチを見せて」と頼めばよい)
- 新しい方向性を試したい: 現在の版から新しいブランチを切って編集する。ボツならそのブランチを放置すればよく、こちらのファイル一覧が増えることはない
- 試した結果を今後の標準にしたい: そのブランチの内容をこちらのブランチに反映する(マージ)

## 由来

2026-09時点でCraftの「prompt」スペース > 「mid journey」フォルダから移行。当時の実際の制作順は v4(ベース) → v1 → v2 → v3 の順に分岐したもので、Craft上の番号は制作順とは一致しない。
